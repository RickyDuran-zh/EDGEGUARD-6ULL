# EBF6ULL S1 Pro 引脚映射

## 外设资源物理引脚映射
### 板载/外接传感器
#### MPU6050 陀螺仪                   
>UART4_TXD -> I2C1_SCL 
UART4_RXD -> I2C1_SDA 
I2C地址：0xD0 -> 0x68 
复用配置：MX6UL_PAD_UART4_RX_DATA__I2C1_SDA MX6UL_PAD_UART4_TX_DATA__I2C1_SCL
##### AP3216C IR(红外LED) + ALS(环境光传感) + PS(接近传感器) 传感器组
>UART4_TXD -> I2C1_SCL 
UART4_RXD -> I2C1_SDA     
I2C地址：0x1E         
#### DS18B20(需要购买) 温湿度传感器接口   GPIO1_2 
### 本地输入输出
#### 用户LED
>SNVS_TAMPER3 -> GPIO5_IO03 
MX6ULL_PAD_SNVS_TAMPER3__GPIO5_IO03
#### RGB LED 配置成普通GPIO或者PWM调光
>Red  GPIO_4(GPIO1_IO04) -> pwm3.OUT 
gpio: MX6UL_PAD_GPIO1_IO04__GPIO1_IO04
PWM: MX6UL_PAD_GPIO1_IO04__PWM3_OUT

>Green CSI_HSYNC -> pwm8.OUT 
gpio: MX6UL_PAD_CSI_HSYNC__GPIO4_IO20
PWM: MX6UL_PAD_CSI_VSYNC__PWM8_OUT

>Blue CSI_VSYNC -> pwm7.OUT 
gpio: MX6UL_PAD_CSI_VSYNC__GPIO4_IO19
PWM: MX6UL_PAD_CSI_VSYNC__PWM7_OUT
#### 按键 
>SNVS_TAMPER1 -> GPIO5_IO01  MX6ULL_PAD_SNVS_TAMPER1__GPIO5_IO01
#### 蜂鸣器  
>UART1_RTS -> GPIO1_IO19 MX6UL_PAD_UART1_RTS_B__GPIO1_IO19 
#### 可调电阻
