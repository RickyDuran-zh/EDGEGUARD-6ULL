# EdgeGuard LCD UI 当前设计与优化方向

> 更新日期：2026-06-17 | 状态：已部署

---

## 整体架构

```
┌── 顶栏 (34px) ── EdgeGuard 6ULL · RickyDuran ──── [退出登陆] ──┐
│                                                                  │
│  主内容区 QtStackedWidget (左右滑动 + 底部按钮切换, 150ms 动画)     │
│                                                                  │
├── 底部栏 (42px) ── [监控中心] [传感器] [报警] [系统] [摄像头] [图表] ──┤
```

- 屏幕分辨率：800×480
- UI 框架：Qt 5.11.3 + linuxfb
- 数据刷新：QTimer 500ms 轮询 `/tmp/edgeguard_status.json`
- 切页方式：手指左右滑动（带动画）+ 底部按钮点击（瞬间切换）
- 字体：思源宋体 (Source Han Serif SC)

## 7 页详情

### 页 0 — 登录页

| 元素 | 说明 |
|------|------|
| 标题 | EdgeGuard 6ULL · RickyDuran |

### 页 1 — 监控中心

```
标题: 监控中心                              [运行中/演示/服务断开]

┌──────────────┬──────────────┐
│   系统状态     │   报警原因     │  ← 状态中文化 (正常/警告/报警/故障)
├──────────────┼──────────────┬──────────────┐
```

## 数据流

```
sensor_hubd (I2C 读传感器) → 评估状态 → /tmp/edgeguard_status.json
                                              ↓ QTimer 500ms
edgeguard_visiond (V4L2 摄像头) → /tmp/edgeguard_vision.json
                                              ↓
                                        LCD UI 读取 + 渲染

用户操作 (静音/确认/演示) → /tmp/edgeguard_cmd.json → sensor_hubd 处理
```

## 已知限制

| 问题 | 原因 | 影响 |
|------|------|------|
| UI 延迟比 LED 慢 ~1s | LED 是 GPIO 直驱，UI 是文件轮询 | 监控中心状态滞后于物理指示灯 |
| 演示模式 ALARM 窗口短 | 30 phase 中仅 5 个 ALARM (2.5s) | 红灯一闪而过 |
| 表盘颜色阈值硬编码 | 60/30/0 写死，未读 sensor_hubd 配置 | 与实际告警阈值不同步 |
| 传感器页纯数字 | 缺柱状图/趋势指示 | 可视化弱 |

## 后续优化方向

| 优先级 | 方向 | 说明 |
|--------|------|------|
| P1 | 表盘阈值动态化 | CircularGauge 颜色分区从 config JSON 读取，与 sensor_hubd 保持一致 |
| P2 | 刷新率提升 | QTimer 500ms → 250ms，延迟减半 |
| P2 | 传感器页可视化 | 加速度/陀螺仪加简易指示条，数字+背景色 |
| P3 | 报警历史列表 | LCD 端增加 SQLite 查询展示（Web 端已有） |
| P3 | 人脸识别登录 | FaceLoginPage + 摄像头预览 + visiond 模式切换（详见 p3-face-login-plan.md） |
| P4 | 摄像头实时预览 | JPEG 帧中继，3-4 fps |
| P4 | 主题切换 | 深色/浅色模式 |

## 核心文件

| 文件 | 用途 |
|------|------|
| `ui/mainwindow.h/cpp` | 主窗口：页面构建、状态刷新、导航控制 |

| `ui/qtstackedwidget.h/cpp` | 滑动容器：左右手势 + QPropertyAnimation |

| `ui/EdgeGuardUI.pro` | Qt 项目文件 |
