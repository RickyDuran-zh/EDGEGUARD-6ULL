# EdgeGuard UI 重构与扩展方案

> **状态**：规划中 | 最后更新：2026-06-08 | **不修改当前代码，纯方案设计**

---

## 0. 现状分析

### 0.1 当前 UI 概况

| 维度 | 现状 | 问题 |
|------|------|------|
| 技术栈 | Qt5 + linuxfb + raw evdev 触摸 | 无窗口管理器，所有交互需自己实现 |
| 分辨率 | 800×480 LCD | 空间有限，需精心布局 |
| 页面 | 5 页 QStackedWidget | 功能分类不够清晰 |
| 交互 | 上下滑动切页、侧边栏点击、键盘 1-5 | 无文字输入能力、无确认/取消对话框 |
| 数据 | 读 status.json（500ms 刷新）、写 cmd.json | 单向为主，反向控制能力弱 |
| 认证 | **无** | 任何接触板子的人都能操作 |
| 摄像头 | **无** | 无图像显示能力 |
| 配置 | Settings 页仅展示阈值 | 不能修改任何配置 |

### 0.2 核心痛点

1. **无安全边界**：板子暴露在物理环境中，任何人都能操作 UI、发送命令
2. **无输入能力**：没有虚拟键盘，无法输入文字（用户名、密码、配置值、搜索）
3. **交互单一**：只有静音和确认两个按钮，无法修改配置、无法浏览历史
4. **视觉能力缺失**：未来加入摄像头后没有展示页面
5. **数据展示弱**：阈值只读、报警历史无翻页、系统日志不可见

## 1. 设计目标

### 1.1 核心原则

- **帧缓冲优先**：所有 UI 组件必须在 linuxfb 下工作，不依赖 X11/Wayland
- **触摸友好**：按钮最小 44×44px（手指可点），滑动和手势兼容
- **安全分层**：操作分"游客"和"管理员"两个权限级别
- **渐进增强**：新功能按优先级分阶段实现，不破坏现有功能

## 2. 新功能模块

### 2.1 登录与认证系统

#### 2.1.1 登录页（首页，所有功能的前置页面）

**两种认证方式**：

| 方式 | 描述 | 实现难度 |
|------|------|---------|
| **PIN 码** | 6 位数字，虚拟数字键盘输入 | :yellow_circle: 中 |
| **人脸识别** | 摄像头拍摄 + ncnn 特征比对 | :red_circle: 高 |
| **混合模式** | PIN 为主，人脸为快速解锁辅助 | :yellow_circle: 中 |

**PIN 登录流程**：
```
启动 → 登录页面
       ├── 显示摄像头预览（左上角小窗）
       ├── 6 位 PIN 输入框（密码圆点 ●）
       ├── 虚拟数字键盘（0-9 + 退格 + 清除）
       ├── [人脸识别] 按钮
       └── 输入正确 → 淡入动画 → 进入主导航
           连续 3 次错误 → 锁定 30 秒 + 蜂鸣器告警
```

**人脸识别登录流程**（远期）：
```
点击 [人脸识别]
  → 摄像头捕获一帧
  → ncnn 人脸检测（检测画面中是否有面部）
  → ncnn 人脸特征提取（128/512 维特征向量）
  → 与本地注册库比对（2-5 个已注册用户）
  → 匹配成功 → 登录
  → 匹配失败 → 提示重试，3 次失败回退到 PIN
```

**自动锁定**：
- 可配置空闲时间（默认 60 秒无触摸）
- 锁定后回到登录页
- 解锁恢复之前的页面状态

#### 2.1.2 虚拟键盘组件（`VirtualKeyboard` Widget）

这是整个 UI 的基础设施，所有需要文字输入的地方都依赖它。

**设计要点**：
- 自绘 QWidget，不依赖系统输入法
- 支持两种布局：**数字键盘**（PIN、IP 地址）和 **全键盘**（用户名、搜索）
- 弹出式，从屏幕底部滑入，点击外部收起
- 按键最小 44×44px，间距 4px

**数字键盘布局**（240×280，居中）：
```
┌───────────────┐
│ PIN: ● ● ● ●  │  ← 输入预览
├───┬───┬───┬───┤
│ 1 │ 2 │ 3 │ ⌫ │
├───┼───┼───┼───┤
│ 4 │ 5 │ 6 │   │
├───┼───┼───┤ ✕ │
│ 7 │ 8 │ 9 │   │
├───┼───┼───┼───┤
│ * │ 0 │ # │ ✓ │
└───┴───┴───┴───┘
```

**全键盘布局**（800 宽，下半屏弹出）：
```
┌──────────────────────────────────────────────────┐
│ 输入: [____________________________] [✕]         │
├───┬───┬───┬───┬───┬───┬───┬───┬───┬───┬───┬───┤
│ q │ w │ e │ r │ t │ y │ u │ i │ o │ p │ ⌫ │   │
├───┼───┼───┼───┼───┼───┼───┼───┼───┼───┼───┤ ✓ │
│ a │ s │ d │ f │ g │ h │ j │ k │ l │ - │ _ │   │
├───┼───┼───┼───┼───┼───┼───┼───┼───┼───┼───┼───┤
│ ⇧ │ z │ x │ c │ v │ b │ n │ m │ , │ . │ / │ @ │
├───┼───┼───┼───┴───┼───┴───┼───┴───┼───┼───┼───┤
│123│ ; │ : │ SPACE          │ .com  │ ← │ → │   │
└───┴───┴───┴───────────────┴───────┴───┴───┴───┘
```

**技术实现**：
- 每个按键 = QPushButton + 圆角样式
- 按键事件 → 发射 `keyPressed(QString)` 信号
- 输入缓冲在调用方维护，VirtualKeyboard 只负责发射按键字符
- 支持长按退格连续删除

### 2.2 摄像头 + AI 视觉页面

#### 2.2.1 页面布局

```
┌──────────────────────────────────────────┐
│  Camera View                     [⚙]    │  ← 顶栏
├──────────────────────────────────────────┤
│                                          │
│         ┌──────────────────┐            │
│         │                  │            │
│         │   实时摄像头画面   │            │  ← 640×480 或 800×480
│         │   + AI 检测框    │            │
│         │                  │            │
│         └──────────────────┘            │
│                                          │
├──────────────────────────────────────────┤
│  Status: ● online  | Faces: 1  | Motion: Y │  ← 状态栏
├──────────────────────────────────────────┤
│  [拍照]  [相册]  [运动检测: 开/关]       │  ← 操作栏
└──────────────────────────────────────────┘
```

#### 2.2.2 功能清单

| 功能 | 触发方式 | 说明 |
|------|---------|------|
| 实时预览 | 进入页面自动开始 | 1-2 fps JPEG 解码显示，不是视频流 |
| AI 检测叠加 | 自动（如果有 visiond） | 人脸框（绿色=熟人，红色=陌生人）、运动区域高亮 |
| 手动拍照 | 点击 [拍照] | 保存全分辨率快照到本地 |
| 快照相册 | 点击 [相册] | 网格缩略图（3×2），点击放大查看 |
| 运动检测开关 | 切换按钮 | 关闭时只拍照不检测，节省 CPU |
| 报警联动 | 自动 | 状态机进入 ALARM → 自动连拍 3 张 → 弹出通知 |

#### 2.2.3 技术要点

- **JPEG 解码**：Qt5 自带 `QImage::fromData()` 直接解码 JPEG，无需额外库
- **低帧率显示**：用 QTimer 2000ms 周期读 vision.json 中的 snapshot_path，加载并显示
- **AI 检测框叠加**：vision.json 中返回人脸坐标数组 `[[x,y,w,h], ...]`，QPainter 画矩形覆盖
- **相册存储**：`/var/log/edgeguard/snapshots/`，文件名含时间戳，最多保留 100 张自动循环

### 2.4 交互增强

#### 2.4.1 系统弹窗组件

需要自绘一套弹窗系统（linuxfb 没有原生对话框）：

| 弹窗类型 | 场景 | 按钮 |
|---------|------|------|
| **确认框** | 重启服务、删除报警日志 | [取消] [确认] |
| **输入框** | 修改阈值、设置 IP | 虚拟键盘 + [取消] [确定] |
| **通知条** | 报警触发、服务离线 | 顶部滑入，3 秒自动消失 |
| **选择列表** | 切换网口、选择报警类型筛选 | 可滚动列表 + 点击选中 |
| **加载中** | 模型加载、服务启动等待 | 旋转动画 + "Loading..." |

#### 2.4.2 手势交互

| 手势 | 页面 | 动作 |
|------|------|------|
| 单指上滑 | 任意 | 下一页 |
| 单指下滑 | 任意 | 上一页 |
| 单指左滑 | Camera | 上一张快照 |
| 单指右滑 | Camera | 下一张快照 |
| 长按（>800ms） | 列表项 | 弹出操作菜单（查看/删除/导出） |
| 双指捏合 | Camera | 缩放照片 |
| 双击 | Camera | 全屏/退出全屏 |

#### 2.4.3 阈值滑块编辑器

Settings 页当前只展示阈值数字。改为交互式滑块：

```
┌──────────────────────────────────────────┐
│  Motion Alarm Threshold                  │
│  ├────●──────────────┤  15000           │
│  0              30000                    │
│                                          │
│  PS Alarm Threshold                      │
│  ├─────────●─────────┤  220             │
│  0               500                     │
│                                          │
│  [恢复默认]           [保存配置]         │

- 滑块改变 → 写 cmd.json 命令 `set_config:{key:value}`
- sensor_hubd 收到后更新配置并写回 config.json
- UI 刷新后看到确认值

### 2.5 数据可视化增强

#### 2.5.1 实时传感器曲线（Sensors 页）

```
┌──────────────────────────────────────────┐
│  Motion Delta (最近 60 秒)                │
│  ┌──────────────────────────────────────┐ │
│  │ ██                                   │ │
│  │ ██     ██                            │ │
│  │ ██   ██████    ██                    │ │
│  │ ██████████████████████               │ │  ← 折线图
│  └──────────────────────────────────────┘ │
│  0s                  30s             60s  │
└──────────────────────────────────────────┘

- 在内存中维护 120 个数据点（60 秒 @ 500ms）
- QPainter 自绘折线图，不依赖第三方图表库
- 每条线不同颜色：运动(蓝)、光照(黄)、接近(红)
- 背景画 WARNING/ALARM 阈值参考线（虚线）

```
┌──────────────────────────────────────────┐

## 3. 页面路由设计

```
                    ┌─────────┐
                    │  LOGIN  │ (启动首页，锁定后回到此)
                    └────┬────┘
                         │ 认证通过
                         ▼
              ┌──────────────────┐
              │    DASHBOARD     │ (默认首页)
              └────────┬─────────┘
                       │
        ┌───┬───┬──────┼──────┬───┬───┐

     SENSORS CAMERA ALARMS CONTROL SETTINGS ABOUT
        │   │   │      │      │   │   │
        └───┴───┴──────┴──────┴───┴───┘
                       │

**转场动画**（可选，低优先级）：
- 左右滑动 → 水平推入推出（250ms）
- 页面跳转 → 淡入淡出（200ms）
- 弹窗 → 缩放弹出（150ms）

## 7. 风险与注意事项

| 风险 | 说明 | 缓解 |
|------|------|------|
| **linuxfb 无原生控件** | 所有弹窗、键盘、列表都需自绘 | 封装独立 Widget，充分复用 |
| **800×480 空间有限** | 太多元素会拥挤 | 使用分层、折叠面板、弹窗承载次要内容 |
| **JPEG 解码 CPU 占用** | 每 2 秒解码一帧 640×480 JPEG | Qt 内部用 libjpeg，~10-20ms，问题不大 |
| **QPainter 绘图性能** | 折线图、检测框叠加可能卡顿 | 缓存到 QPixmap，只在数据变化时重绘 |
| **触摸事件与文本输入冲突** | 虚拟键盘弹出时滑动可能误触 | 键盘弹出时屏蔽页面滑动，只响应键盘区域 |
| **向后兼容** | 重构不能破坏现有功能 | 保留所有现有页面，逐步迁移，不删除旧代码直到新功能稳定 |
